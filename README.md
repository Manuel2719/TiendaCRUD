# TiendaCRUD 🛒 - C# Windows Forms

Sistema CRUD de Tienda en C# desarrollado en Visual Studio.

### Estructura del Proyecto
- Form1.cs: Interfaz principal y lógica CRUD (Create, Read, Update, Delete)
- Form1.Designer.cs: Diseño de formulario
- Program.cs: Punto de entrada
- TiendaCRUD.csproj: Configuración del proyecto

### Funcionalidades CRUD
1.  CREATE: Botón Agregar producto (ID, nombre, precio, stock)
2.  READ: DataGridView que lista productos
3.  UPDATE: Botón Actualizar por ID
4.  DELETE: Botón Eliminar por
